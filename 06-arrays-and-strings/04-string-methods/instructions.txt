TOPIC: String Methods

OBJECTIVE
Learn common methods for searching, checking, modifying, and splitting Strings.

CONCEPTS
- contains()
- startsWith()
- endsWith()
- indexOf()
- replace()
- trim()
- split()

PRACTICE
1. Check whether a String contains specific text.
2. Check its beginning and ending.
3. Find the position of characters or text.
4. Replace text within a String.
5. Remove surrounding whitespace.
6. Split a String into multiple parts.

CHALLENGE
Build a small String analyzer that performs several operations
on user-provided text.
