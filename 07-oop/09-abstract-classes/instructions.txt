TOPIC: Abstract Classes

OBJECTIVE
Learn how to create base classes that define common structure
while requiring child classes to provide specific behavior.

CONCEPTS
- abstract classes
- abstract methods
- Concrete methods
- Implementing abstract methods
- Cannot instantiate abstract classes
- Polymorphism with abstract classes

PRACTICE
1. Create an abstract parent class.
2. Add an abstract method.
3. Add a normal method.
4. Create child classes that implement the abstract method.
5. Use parent references to work with child objects.

CHALLENGE
Create an abstract class representing a real-world concept and
multiple child classes with different implementations.
