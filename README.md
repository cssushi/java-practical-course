# Java Practical Course

A hands-on Java learning course built from the ground up.

This repository is designed to be learned sequentially. Each topic contains practical Java programs and exercises rather than only theoretical notes.

## Course Structure

### Level 01 — Java Basics
Fundamental Java syntax and language concepts.

- Hello World
- Comments
- Variables
- Data Types
- Type Casting
- Constants

### Level 02 — Operators
Working with Java operators.

- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Assignment Operators
- Increment & Decrement

### Level 03 — Input & Output
Interacting with the user through the console.

- Scanner
- User Input
- Output Formatting

### Level 04 — Control Flow
Controlling program execution.

- if / else
- switch
- for loops
- while loops
- do-while loops
- break / continue

### Level 05 — Methods
Breaking programs into reusable pieces.

- Basic Methods
- Parameters
- Return Values
- Scope
- Method Overloading

### Level 06 — Arrays & Strings
Working with collections of values and text.

- Arrays
- Multidimensional Arrays
- Strings
- String Methods
- StringBuilder

### Level 07 — Object-Oriented Programming
The core of Java programming.

- Classes & Objects
- Constructors
- this
- Encapsulation
- Inheritance
- super
- Method Overriding
- Method Overloading
- Polymorphism
- Abstract Classes
- Interfaces

### Level 08 — Exception Handling
Handling errors safely.

- try / catch
- finally
- throw
- throws
- Custom Exceptions

### Level 09 — Collections & Generics
Working with flexible data structures.

- ArrayList
- LinkedList
- HashSet
- HashMap
- Iterators
- Generics

### Level 10 — File I/O
Reading and writing data.

- Reading Files
- Writing Files
- Buffered I/O

### Level 11 — Modern Java
Modern Java programming techniques.

- Lambdas
- Functional Interfaces
- Streams
- Optional

### Level 12 — Multithreading
Concurrent programming.

- Thread Basics
- Multiple Threads
- sleep()
- join()
- Shared Data
- Race Conditions
- synchronized
- Executors

### Level 13 — Projects
Putting everything together.

- Calculator
- Student Management System
- Bank System
- Library Management System
- Final Project

---

## How to Use This Repository

Work through the levels sequentially.

Each topic contains:

- `instructions.txt` — what to learn and practice
- `.java` files — practical implementations and exercises

Compile Java programs with:

```bash
javac FileName.java
